# Practice Task 1 — Unit Testing

**Course:** Automated Software Testing with JavaScript  


---

## Description
This project implements unit testing in JavaScript using **Mocha** and **Chai**.  
It also includes:
- Code coverage via **c8**
- Linting with **ESLint**
- Transpilation using **Babel**
- Pre-commit checks with **Husky**
- Continuous integration using **GitHub Actions**

---
##  Running Tests

Run all tests and generate an HTML report:

```
  npm test
```

---
##  Code Coverage

Run coverage analysis:

```
npm run coverage
```
